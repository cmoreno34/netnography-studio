Estudios de Mercado I · Tema 3 — Netnography worksheet (P06B)

Treat one YouTube video as a field site. Grab its comments — customers talking unprompted — read them as qualitative data, and code them to themes and a decision. Companion to practical P06B.

1 Bring the comments in

Pick a video with a rich comment thread. Open it, copy a good batch of comments, and paste them below — the comments are your data.

Open video ▶
How to grab the comments (30 seconds, no login):
  1. Open the video and scroll down to the comments; set them to Top comments.
  2. Scroll a bit so 40–60 load, then select from the first comment down and copy (Ctrl/Cmd+C).
  3. Paste into the box below. Don't worry about the likes/reply lines — paste as-is.

2 Immerse, then code to themes

Read enough to learn the vocabulary before you code. The prompt below already includes the comments you pasted — it runs the thematic analysis, uses AI as a second coder, and asks for a thematic map.
